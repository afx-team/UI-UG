# UI-UG1 model releases

The UI-UG1 checkpoints remain hosted at:

- [UI-UG-7B](https://huggingface.co/afx-team/UI-UG-7B)
- [UI-UG-7B-2601](https://huggingface.co/afx-team/UI-UG-7B-2601)

The original inference/evaluation code, example datasets, requirements, figures, and README are together in the parent [UI-UG1 archive](../README.md). No checkpoint binaries are included in this repository.

For original commands and relative paths, run them from `uiug_v1/`, using the original requirements in a separate environment. For UI-UG 2, use the repository root and [afx-team/UI-UG2-4B](https://huggingface.co/afx-team/UI-UG2-4B).
